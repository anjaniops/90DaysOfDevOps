🚀 Day 39 – What is CI/CD?

Today I focused on understanding the fundamentals of CI/CD (Continuous Integration and Continuous Delivery/Deployment) before building any pipelines.

📚 What I Learned

- Difference between Continuous Integration, Continuous Delivery, and Continuous Deployment
- Common challenges with manual deployments
- Why "It works on my machine" is a real software delivery problem
- CI/CD pipeline anatomy:
  - Trigger
  - Stage
  - Job
  - Step
  - Runner
  - Artifact
- Designed a basic CI/CD pipeline from GitHub Push → Build → Test → Docker Image → Staging Deployment
- Explored a real GitHub Actions workflow from an open-source project

📁 Files Included

- "day-39-cicd-concepts.md"
- CI/CD pipeline diagram
- Research notes on CI/CD concepts

🎯 Key Takeaway

CI/CD is not just about automation tools—it's a software delivery practice that helps teams build, test, and deploy applications faster, more reliably, and with greater confidence.
