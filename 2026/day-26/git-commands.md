## GitHub CLI Commands (gh)

| Command | Description |
|---------|-------------|
| `gh auth login` | Authenticate with GitHub |
| `gh repo create` | Create new repo |
| `gh repo clone` | Clone repo |
| `gh repo list` | List all repos |
| `gh issue create` | Create issue |
| `gh issue list` | List issues |
| `gh pr create --fill` | Create PR auto-fill |
| `gh pr merge --squash` | Merge PR |
| `gh run list` | List workflow runs |
| `gh release create` | Create release |
| `gh api /user` | Raw API call |
| `gh gist create` | Create gist |
